    What this does and does not measure

    Every figure above is computed from this repository's git history — commits, diffs, authorship, and the current file tree. Nothing is estimated, sampled, or inferred by a model. Running the same measurement on the same commit always produces the same numbers, and the digest below is how you check that.

    It measures how the code has moved, not whether the code is good. It cannot see product quality, customer impact, architectural fitness, or anything that happened outside version control. A file that scores calmly here can still be wrong; a file that scores hot may be under deliberate, healthy redevelopment. Treat every finding as a place to look, not a verdict.
